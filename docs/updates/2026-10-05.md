## 保留与略过

- 保留通用运行层、项目安装器、默认继承宿主模型、工具能力检查，以及没有多代理、历史 API 或调度器时的降级。单代理重复评审仍不构成独立佐证。
- 保留上次本机 pi 验证得到的引用行号检查，以及适用于不同模型的相邻回归、自证、完整 diff 审查和减少无意义通知的规则。上游部分删减明确针对特定 Opus 版本，本仓库不照搬。
- 不导入 Cursor 插件元数据、界面安装指引、固定厂商模型 ID、私有聊天路径、`/loop` 等宿主专用命令。
- 不采用为读取连接器而请求写权限、无条件把 PR 标记 ready、重置脏工作树等行为。修改本地内容前保留用户工作，PR 证明未完成时用草稿。
- 现有 orchestrator 和 GitHub watcher 没有相关源码更新，继续作为可选工具，读取技能不依赖它们。

## 升级

拉取 main 或解压 v0.2.0，然后在同一项目重跑安装命令：

```sh
python3 scripts/install.py --target /absolute/path/to/project --entrypoint AGENTS.md
```

使用原来的入口文件名。安装器保留用户模型配置、非托管文件和原有指令；本地修改冲突时在写入前停止。新包包含 53 个技能。
